## About

I'm a self-taught independent developer. I mostly write Java, and I pick up other languages when a project needs them.
Most of my work goes into NeoForge server mods for [Team-Arcadia](https://github.com/Team-Arcadia), the team behind the Arcadia: Echoes of Power modpack.
